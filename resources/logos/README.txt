这里的 SVG 是各平台的品牌标识，用来说明"这一行加速的是哪个平台"。

来源：Simple Icons（https://simpleicons.org）
  · 图标本体以 CC0 1.0 通用许可发布；
  · 但**品牌标识与商标归各自所有者**（Valve / Discord / Twitch / EA /
    Ubisoft / GitHub / Google / Cloudflare 等），此处仅作**指明性使用**
    （nominative use）—— 表示"此功能与该平台对接"，不代表任何隶属或背书关系。

文件对应关系：
  steam.svg           → Steam 服务
  discord.svg         → Discord 语音聊天
  twitch.svg          → Twitch 直播
  ea.svg              → Origin（EA 现已更名为 EA App）
  ubisoft.svg         → Uplay（Ubisoft Connect）
  cloudflare.svg      → 公共 CDN（Cloudflare 是这些站点最常走的 CDN）
  github.svg          → Github
  googletranslate.svg → Google 翻译

另有「国外验证码平台」与「图床」两项**不在此目录**：它们是"类别"而不是单一品牌
（验证码有 hCaptcha / reCAPTCHA / Turnstile 等，图床更是各家都有），
所以界面里用自绘的通用矢量图标，避免把某个品牌错当成整个类别。
