# Yuhub 功能总览（代码实测版）

> 依据源码逐模块核对，不代表 README 的宣传口径。核对日期 2026-11-04，对应 `VERSION = "1.3.1"`（`ui/__init__.py:673`）。
> 说明：README 正文仍停在 v1.1.9，1.3.0（帧驱动动画引擎）与 1.3.1（矢量水墨鲤）只在 `ui/__init__.py` 的版本注释里。

## 一句话定位

Windows 单文件工具箱（Python + PySide6，PyInstaller 单 exe，当前产物 `dist/Yuhub.exe` ≈ 56.3 MiB），
以 `requireAdministrator` 启动，9 个功能页 + 一批可脱离 Qt 独立测试的纯标准库引擎。

设计取向：极简色块视觉、能离线就离线、核心引擎不依赖 Qt。

## 一、九个功能页（侧栏顺序，`ui/main_window.py:91` NAV_ITEMS）

### 1. 首页 `home`
- 上半屏：水墨鱼池横幅（自绘动画，中央叠 "yuhub" 大字 + 版本号）
- 左下：本机配置（CPU / 显卡 / 内存 / 硬盘 / 主板 / 系统，`hardware.py` 离线采集，判定笔记本/台式）
- 右下：实时监控（CPU / 内存 / 磁盘 / 网络 / 显卡，带迷你趋势条，可展开详情）
- 按用户要求**不含功能快捷入口**，入口统一走侧栏

### 2. C 盘清理 `cleaner`
- 规则集：**64 条规则 / 7 个分组**（临时文件 18、缓存文件 16、显卡缓存 3、系统相关 8、过期文件 10、应用程序 5、备份文件 4），移植自 Dism++ `Data.xml`
- 流程：进页自动只读扫描 → 分组勾选 → 二次确认 → 清理 → 结果汇总
- 删除链路：逐项按 WinError 分类（32/33 占用→跳过、5 权限→摘只读 + takeown + icacls 重试、其余算失败）；
  超长路径加 `\\?\`；符号链接/目录联接只删链接不跟进
- 扫描四道保险：每规则 90 秒预算、每 256 项查取消、DISM 分析可 kill（Popen 轮询，上限 120s）、子进程 stdin=DEVNULL
- 结果分开报「N 项正被程序使用，已跳过」/「N 项权限不足或无法删除」
- 「Windows 下载缓存」先停 `wuauserv` / `bits` 再清

### 3. 内存优化 `memory`
- 一键回收：工作集回收 + 系统缓存清理，**不结束任何进程**，跳过关键系统进程与前台窗口
- 定时优化：15 / 30 / 60 / 120 / 240 / 480 分钟 + 自定义（硬下限 15 分钟）
- 过载自动优化：70 / 75 / 80 / 85 / 90% 阈值，触发后 10 分钟冷却；与定时是两套独立规则
- 自动触发路径**不做需要额外提权的动作**（避免后台弹 UAC）
- 优化记录标注触发来源（手动 / 定时 / 过载）

### 4. 软件卸载 `uninstall`
- 枚举本机全部已安装程序（含 Store 应用），真实图标，名称/厂商/版本/体积/安装日期
- 支持搜索、排序、筛选系统组件
- 卸载：调官方卸载器 → 自动深度扫描残留（文件 + 注册表）→ 可勾选 → 二次确认清理
- 卸载器损坏时走「强制清除残留」
- 权限处理：先摘只读 → 判真·权限失败（仅 winerror 5）→ `takeown / icacls` 夺所有权重试

### 5. 多线程下载 `download`
- 粘贴链接 → 探测真实文件名与大小 → 选保存位置 → 分块并发下载
- 并发数**自动取本机逻辑处理器数**（已删除低/中/高档位），界面只如实显示实际线程数
- 指标格：已下载 / 总大小 / 瞬时速度 / 剩余时间；每分块一个色块可视化
- 支持取消与续传；进度用 200ms 轮询快照（避免高频信号冲垮主线程）

### 6. 屏幕共享 `share`
- 一个「开始共享」按钮，模式由**选中的网卡**决定：局域网 IP → 局域网共享（6 位随机观看码）；EasyTier 虚拟网卡 → 异地共享（观看码由房间码+密码派生，不广播）
- H.264 编码（`h264codec.py` 用 ctypes 直调 libavcodec），抓屏与编码双线程，帧率不设上限
- 画质三档 480p / 720p / 1080p（对应约 1 / 2.5 / 5 MB/s），码率按实测吞吐自适应 0.25×~1.6×
- 静止画面优化：1/4 采样签名比较，无变化只发 17 字节心跳（0.5s 一次）+ 每秒兜底刷新
- 可共享整屏或**单个可见窗口**（自动滤掉最小化窗口）
- 每个观看者只保留一格「最新帧」信箱，慢的人掉帧不拖累别人；上限 8 人
- 观看端支持**全屏观看**（独立无边框顶层窗口，Esc / F11 / 双击退出）
- 房间内成员列表可直接「看屏幕」跳转并自动填地址与观看码
- 停止共享/退房即关监听、释放端口
- 传输层自研：单条 TCP + 17 字节帧头协议（`screenshare.py`），不嵌浏览器内核 / WebRTC / 公网隧道

### 7. 异地联机 `lan`
- 内嵌 EasyTier，无房主/成员之分：同房间码 + 密码即进同一虚拟局域网
- 准入校验：进房后探测是否有其他节点，码/密码错明确报错并断开
- 成员发现「三信号并集」：ARP 表 ∪ 昵称信标 ∪ `easytier-cli` core 权威成员表（2.5s 轮询，管理端口 15889）
- 成员行：昵称、虚拟 IP（独立复制按钮，可按游戏给 IP 或 IP:端口）、正在玩的游戏、中继/直连贴片、延迟丢包 tooltip
- 中继诊断：`relay_status()` 从本次会话日志统计「握手成功中继数 / 失败数 / 同网络成员数」，区分"本机没连上中继"与"对端没进来"，各给不同处置建议
- 日志降噪：去重键归一化（剥时间戳、数字折叠），已连上中继时单节点失败降级为提示
- 房间聊天：头像（昵称首字 + 哈希稳定取色）+ 昵称/时间 + 左右分侧；文件消息成文件卡（扩展名色块 + 名称 + 体积 + 下载按钮 + 进度行）
- 临时云盘：拖文件进框即分享（走 `ui/nativedrop.py` 的原生 `WM_DROPFILES`，因为提权进程收不到 Qt 的 OLE 拖放）；下载每次自选保存位置；退房即从所有人列表消失；文件不经服务器
- 中继节点测速（`node_probe.py`）：进页自动测一次 + 手动「测速」，带「延迟数据 x 分钟前」时间戳，不做定时重测
- 内置节点池覆盖国内多地 + 中国香港 + 海外，含 WSS/WS 中继（应对只放行 80/443 的网络）
- 虚拟 IP 由 EasyTier DHCP 分配；IP 变动会提示，可随时「刷新」
- 已开 UDP 广播中继（Minecraft 等依赖局域网广播发现的游戏可见彼此）；切 WiFi/热点自动关虚拟局域网

### 8. 网络加速 `accel`
- Steam++（Watt Toolkit）同形态：平台列表（勾选框 + 品牌 logo + 名称）+ 一键加速 / 停止 / 刷新，勾选持久化
- 内核：`accel-framework/`（.NET 8 + YARP + Native AOT 单文件，约 11.1 MB，无需 .NET 运行时），**内嵌在 exe 里**，进页自动就位到 `%LOCALAPPDATA%\Yuhub\accel`
- 本机 CA 体系：根证书 10 年、叶证书按 SNI 现场签发；私钥只在本机生成、不落盘流量内容
- 流量路径：hosts 指向 127.0.0.1 → 本地 443 反向代理按 SNI 签证书终结 TLS → 转发到预先解析的真实 IP（上游证书照常校验，不做内容篡改）
- hosts 改写带 `# >>> YuhubAccel v1 >>>` 标记块 + 时间戳备份；写成功落 `hosts_dirty` 标记，还原成功才抹掉；进页发现脏标记且内核未跑则自动 hosts-clean 自愈
- 就绪后二次校验 hosts 里确有标记块（防"内核在跑但流量不经过它"）
- 框架状态如实显示，未就位时一键加速不可用并给安装入口
- ⚠️ 代码内注释（`accel_page.py` 头部）仍写着"只有界面骨架，还没有加速能力"，是 1.0.7 时期的遗留说明，与实现不符

### 9. 设置中心 `settings`
- 外观：主题包（存于「文档/Yuhub」，含 theme.json / theme.qss / preview.png）、深色 / 浅色 / 跟随系统三态
- 启动与托盘：开机自动启动、关闭窗口时最小化到托盘
- Windows 安全：智能应用控制（SAC）开/关 —— 写 `VerifiedAndReputablePolicyState` 后跑 `CiTool -r`；关闭前二次确认并告知老版 Win11 不可逆；`read_state_ex()` 返回机器可读分类（OK/ABSENT/DENIED/ERROR），没有该功能时置灰并说明原因
- 异地联机组件：EasyTier / easytier-cli 检测与一键修复
- 网络加速框架：框架检测与修复
- 自动检查更新开关 + 手动「立即检查更新」
- 关于（版本号）

## 三、跨切面能力

- **窗口**：全自定义无边框，自绘标题栏（拖动、双击最大化）+ 边缘缩放；边缘判定先用 `topLevelAt()` 确认在主窗口上，避免误吞下拉列表
- **托盘**：关窗驻留，单击恢复、右键退出；托盘菜单单独套样式（独立顶层弹窗不进主窗口 QSS 级联）
- **单实例**：重复启动唤前台，不开第二窗口
- **主题**：全局 QSS 只作用于主窗口，**每个自建对话框必须自己 setStyleSheet**；内联色标签（`small_note` 等）靠动态属性 `smallNote` / `noteWarn` 在主题切换时统一重刷
- **动效（1.3.0 起）**：`ui/motion_engine.py` 帧驱动 —— 全进程一个 FrameClock、三条优先级车道（交互 > 转场 > 装饰）、物理弹簧（改目标不重置速度，可打断）、闲时停表 / 装饰降帧到 ~24fps / 遮挡即停 / 帧耗超 6ms 让装饰层让路
- **水墨鱼（1.3.1 起）**：`ui/fish.py` 矢量俯视鲤，身体一条连续闭合路径（96 点脊柱采样），姿态量化成 24 帧帧表播放、帧间不插值；帧表按 (墨色, 纸色, DPR) 缓存
- **提权**：exe 清单 `requireAdministrator`，启动弹一次 UAC，之后所有特权操作在同一进程内完成
- **文件拖放**：`ui/nativedrop.py` 走原生 `WM_DROPFILES`（提权进程 IL=高，收不到 Explorer 的 OLE 拖放）
- **页面惰性构造**：`main_window._LazyPages`，启动只建首屏，其余点进去才建
- **高 DPI + 响应式**：功能卡片按视口宽度切 3 / 2 / 1 列
- **字体**：随包苹方（PingFang SC）Regular 子集化，注册进本进程不装系统

## 四、自动更新链路

1. 启动后台静默查 GitHub Releases，发现新版本弹窗
2. 下载 → sha256 校验
3. 把自身拷贝到 `%TEMP%\Yuhub_upd_<pid>` 作为替换器，用 `ShellExecuteW(runas)` 启动（参数逐个加引号）
4. **启动暗号握手**：替换器起来第一件事写 ack 文件，主进程拿到才退出；45 秒拿不到就留住窗口并提示可重试
5. 两步改名替换 exe → 重启；失败回滚（跨盘先试拷贝+大小校验+删源，回滚 5 次重试）
6. 全程落 `%LOCALAPPDATA%\Yuhub\update\replace.log`，返回码 0~9 有含义表

判"要不要提权"必须读 PE 清单的 `requestedExecutionLevel`（`updater.exe_requires_elevation()`），读不到一律按需要处理 —— 只看目录可写性会在桌面/下载目录漏判，WinError 740。

## 五、自检体系（15 套）

源码态均可跑，打包态用 `Yuhub.exe --<名字>-selftest <结果.json>`：

`cleaner` / `memopt` / `uninstaller` / `update` / `theme` / `motion` / `share` / `screenshare` / `lan` / `room_chat` / `node` / `gpu` / `sac` / `toast` / `nativedrop`

原则（吃过亏换来的）：
- 断言不能"自洽比较"（既用被测函数又拿它自己的输出当基准）
- 打桩只用于隔离副作用，关键判据必须有一条真调用
- 新增自检必须同步写进 `Yuhub.spec` 的 hiddenimports，否则只在冻结态炸
- 自检失败时 traceback 落 `<结果>.err`（GUI 子系统没有 stderr）

## 七、已知边界（不是 bug，是取舍）

- 观看屏幕共享**也必须装 Yuhub**（不嵌浏览器内核是 exe 压在 50MB 级的前提）
- 网络加速需要装本机根证书；卸载信任后已加速的站点恢复原状
- 异地联机依赖公共中继，走中继时帧率/延迟受中继质量影响（成员行有贴片提示）
- 屏幕共享 H.264 组件按需下载，首次开共享需联网一次
- 未签名 exe 在 Win11 可能被 SAC 直接拦下（无「仍要运行」入口），处理见 `docs/智能应用控制拦截-处理方案.md`
