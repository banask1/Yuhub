# Yuhub — 一个自己动手写的 Windows 系统工具箱

> 本文约 1000 字，用于 GitHub 仓库介绍、Release 说明或社交平台发布。

---

## 为什么会有这个项目

Windows 上从来不缺"系统优化"软件，缺的是**让人敢用的**那一个。市面上的工具箱要么塞满捆绑安装和开机自启的推荐服务，要么用一堆"深度加速""一键飞升"的话术包装几个注册表读写，装完比装之前还卡。我一直想要一个干净的东西：打开就知道它在做什么，关掉就真的走了，不驻留、不联网、不偷偷改我的设置。

Yuhub 就是我自己给自己做的那个东西。它不承诺让电脑"变快"，只做四件具体的事：**看清本机配置、清理 C 盘、多线程下载、异地联机**。没有会员、没有弹窗、没有"发现 127 个问题"的恐吓式扫描。所有操作都摆在一个窗口里，做了什么、删了多少、省了多少空间，都是可核对的数字。

## 它长什么样

界面是完全重写过的 **极简色块风格**，接近 pixelUI 的视觉语言：不透明实心色块、5~6px 小圆角、1px 硬边框，用纯色方块做功能标识。深色模式的底色是近乎纯黑的 `#0b0b0e`，主文字 `#f2f4f8`，对比度约 15:1——晚上关灯用不会糊成一片灰。窗口是无边框自绘标题栏，支持拖拽移动、双击最大化、边缘拖拽缩放，也支持折叠侧边栏。

主题是**可插拔的主题包**，存在「文档 / Yuhub」目录下，每个主题一个文件夹，里面是 `theme.json`（色板）、可选的 `theme.qss`（样式模板）和 `preview.png`。默认主题叫 **YuUI**。你改配色不用碰代码，改 JSON 就行。

## 四个核心功能

**本机配置检测 + 实时占用监控。** 硬件信息完全离线采集，走 CIM/PowerShell 和注册表，不联网、不装第三方库。能看到机型、CPU 物理核与逻辑线程、显卡与显存、内存、逐盘容量与类型。实时监控用 ctypes 走快路径，显卡部分读 `nvidia-smi`，带趋势条和部件详情。

**C 盘清理。** 清理规则集参考 Dism++ 的思路：缩略图缓存、图标缓存、显卡着色器缓存、各类临时目录等。这里有个我花了很久才做对的地方——清理结果的"已清理 XX MB"**不取自磁盘可用空间的差值**，而是真实被删除对象的体积合计。因为实测发现某些环境下"创建文件时可用空间立刻下降，但删除后不回升"，任何基于前后读数差值的统计都会把"删了几百个文件"误报成"什么都没释放"。所以删除前先把体积量出来，删完复查文件确实不存在，确认删掉了才计入。文件被 `explorer.exe` 占用时会按需重启资源管理器再重试，而不是无条件重启。

**多线程下载。** 纯标准库实现，不依赖 Qt，可以独立测试。下载前先探测真实文件名和大小，然后分块并发抓取、边下边写同一个文件，实时显示速度、剩余时间和分块进度。线程档位按本机物理核心数自动适配。

**异地联机。** 内嵌了 EasyTier 的最小二进制集（core + wintun.dll + Packet.dll，Apache 2.0），填同一组房间码和密码就能进入同一个跨网虚拟局域网。房主/成员身份可切换，房主固定虚拟 IP `1`**`0.126.126.1`、成员 `10.126.126.2`（可一键复制），带在线成员列表。切换 WiFi 或热点时会自动关闭虚拟局域网，避**免残留进程。不需要 UPnP、不需要自建服务器、免费。

另外还有**软件卸载与残留清理**：枚举本机全部已安装程序（含应用商店应用），列表里显示每个程序的真实图标，调用各自的卸载器，卸载完深度扫描残留的文件和注册表项，安全可删的自动升权删除。

## 工程上的几个选择

技术栈是 **Python + PySide6**，用 PyInstaller 打成单文件 exe。整个项目最花心思的部分不是功能，而是**可验证性**。打包后的 GUI 程序做自动化测试很麻烦，所以我给每个高风险模块都配了"进程内自检"：

```
Yuhub.exe --theme-selftest   <out.json>   # 主题包系统，22 项
Yuhub.exe --uninstall-selftest <out.json> # 卸载与残留，21 项
Yuhub.exe --lan-selftest                   # 跨网房间全流程
```

自检直接在真实的冻结 exe 里跑，把每一项的结果写成 JSON。这样每次改完代码，一条命令就能确认"打包后的成品"没有回归，而不是只在源码态看着没事。

当前版本 **v0.8.14beta**。这不是"半成品"，而是我决定在功能基本稳定后，从 1.0 之前重新梳理版本线、把命名对齐到实际成熟度的结果。核心的五个页面都已上线可用，异地联机也已经能处理"异地、跨网、有人在国外"这些真实场景，剩下的主要是体验打磨这类周边工作。
