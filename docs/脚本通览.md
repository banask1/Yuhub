## 六、跨模块契约与"静默失效"清单（改单边即失效）

1. **hosts 加速契约**（accel_page ↔ accel-framework）：脏标记文件 `hosts_dirty`、标记块 `# >>> YuhubAccel v1 >>>`、hosts 路径 `%SystemRoot%\System32\drivers\etc\hosts` —— 任一处只改一边这条防线直接失效。语义：写成功即落标记，还原成功才抹，否则进页面自愈。
2. **提权判据铁律**：「exe 需要提权」与「目标目录可写」是两件事，`uac_admin=True` 让每个 exe 都带清单，只探目录可写会漏判 → WinError 740。判"要不要提权"读 PE 清单 `requestedExecutionLevel`，读不到按需要。
3. **`SetMinimumSize` 根治空白**：滚动容器内容控件不要用 `setFixedHeight`，竞态会把每一项压成 0 高。
4. **`widget_origin` 用全局坐标相减**：`mapTo` 在兄弟子树下会偏 (7,7)。
5. **自检最忌"自洽比较"**：断言不能既用被测函数又用它自己的输出做基准。
