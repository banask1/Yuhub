# Yuhub

一个 Windows 系统工具箱，聚焦 **C盘清理**、**内存优化**、**软件卸载**、**多线程下载**、**屏幕共享**、**异地联机** 与 **网络加速**。

> 当前版本 **v1.1** ｜ 📖 项目的来龙去脉与设计取舍见 **[项目介绍](docs/项目介绍.md)**（约 1000 字）

## 下载

从 **[Releases](https://github.com/banask1/Yuhub/releases)** 下载 `Yuhub.exe`，单文件免安装，直接运行。
系统要求 Windows 10 / 11（64 位）。程序以管理员身份启动（exe 清单 `requireAdministrator`，与 Steam++ 同形态），**启动时弹一次 UAC**，之后所有需要权限的操作都在同一个进程里完成、不再反复弹窗。

---

## 这是什么

Yuhub 是一个用 **Python + PySide6** 写的 Windows 桌面工具箱，打包为单文件 `Yuhub.exe`，免安装、直接运行。

设计取向只有两条：**极简色块（近 pixelUI）的视觉语言**，以及**能离线就离线、能用标准库就不引三方依赖**。除 UI 框架与打包工具外，核心引擎（下载、清理、自启、更新、联机编排）全部纯标准库实现，不依赖 Qt，可以脱离界面单独测试。

侧栏共 9 项：**首页 / C盘清理 / 内存优化 / 软件卸载 / 多线程下载 / 屏幕共享 / 异地联机 / 网络加速 / 设置中心**。

## 目前能实现的功能

### 首页
- **本机配置检测**：CPU / 显卡 / 内存 / 硬盘 / 主板 / 系统版本等，完全离线采集，自动判定笔记本或台式机
- **实时占用监控**：CPU、内存、磁盘、网络与显卡占用实时刷新，带迷你趋势条，可展开查看详情

### C盘清理
- Dism++ 风格规则集，扫描后可逐项勾选
- 扫描结果分类汇总，删除前二次确认
- 只清理可安全重建的缓存与临时文件

### 内存优化
- **一键回收**：把各程序占着却不活跃的物理页交还系统，程序照常运行 —— **本功能不会结束任何进程**，关键系统进程与当前最前面的窗口（你正在用的软件）自动跳过
- **管理员深度优化开关**：开启后手动点「立即优化」会额外清空系统备用列表与文件缓存（需要管理员权限；Yuhub 本身就以管理员身份运行，不会再弹授权），可用内存通常还能再涨一截；关闭时只做逐进程回收
- **定时自动优化**：6 个挡位（15 分钟 / 30 分钟 / 1 小时 / 2 小时 / 4 小时 / 8 小时）＋一个「自定义」挡位（自己填分钟数）。**下限 15 分钟**是刻意的：更频繁地回收只会让程序反复重新调页，那是越"优化"越卡
- **内存过载自动优化**：与定时是两套独立规则、可同时开启；占用率达到 70 / 75 / 80 / 85 / 90% 之一时执行一次，触发后 10 分钟冷却
- **两类自动触发都不做需要提权的动作**：不会在后台弹授权窗口；优化记录会标明每条是「手动 / 定时 / 过载」触发的

### 多线程下载
- 分块并发抓取，下载前自动探测真实文件名与文件大小
- 实时显示速度、剩余时间与各分块进度
- 支持取消与续传

### 屏幕共享
- **选哪块网卡，就走哪条链路**：共享只有一个「开始共享」按钮，模式由「本机地址」里选中的网卡决定——选**本地网络地址**就是局域网共享（同一 WiFi / 路由器下直连，观看码是随机 6 位数字，念给朋友即可）；选**异地联机虚拟网卡**就是异地共享（走已经建好的 EasyTier 虚拟局域网）。不用在两个按钮之间维持"地址与按钮是一对"的心智负担，也不会出现"绑着局域网 IP 却按了异地共享"这种自相矛盾的状态
- **H.264 编码，帧率不设上限**：抓屏（GDI）与编码拆成两条工作线程跑，抓屏能跑多快就发多快。画质只决定「分辨率 + 起步码率」——三档 **480p / 720p / 1080p**，对应约 1 / 2.5 / 5 MB/s。码率会按链路实测吞吐**自适应浮动**（0.25× ~ 1.6×）；下探到 0.25× 是刻意的：宁可画质糊一点，也不要掉到 4fps
- **画面没变就不重发**：发送前先按 1/4 采样算一个签名——逐字节比较会被桌面上某个一直闪动的 20×20 小指示器骗过去，**从不命中**——画面没变化时只发 17 字节心跳（每 0.5 秒一次）。看文档、看桌面时几乎不占流量，异地走中继时这条最关键。另有一条每秒一次的兜底刷新，防止采样漏掉真实变化后画面永久停在旧内容上
- **在房间里免输观看码**：已经进了同一个房间的话，队友的成员列表里会直接出现「看屏幕」按钮，点一下就切到本页并自动填好地址与观看码（观看码由房间码 + 密码两边各自算出，**从不广播**）
- **共享屏幕，也能只共享某个窗口**：下拉里列出本机所有可见窗口（自动滤掉最小化的——抓屏抓的是屏幕上的区域，最小化的窗口抓出来只会是一片黑）
- **慢的人只掉帧，不拖累别人**：每个观看者只有一格"最新帧"的邮箱，新帧直接覆盖旧的；发送端不会因为对方带宽不够而堆积内存
- **观看上限 8 人**，本机画面预览实时可见
- **退出即断**：停止共享或退出房间会立刻关闭监听，端口随即释放
- 实现只有一条 TCP 流 + 自研 17 字节帧头协议（`screenshare.py`）；H.264 编码走 `h264codec.py`，**ctypes 直调 libavcodec**。EasyTier 是内置随包的，FFmpeg 组件则**按需下载**（首次开共享时后台拉一次、装好后离线可用），本体 exe 因此保持在 50MB 上下。**不带浏览器内核、不带 WebRTC、不带公网隧道**——这是把 exe 压在 50MB 级的关键
- **观看端可以全屏观看**：画面区上方有「全屏观看」按钮（**双击画面**也行）。进去是一块纯黑的独立全屏窗口，整块屏只放画面，`Esc` / `F11` / 双击画面退出，鼠标一动浮出「怎么退出」的提示条再自动淡出。它**不是**把主窗口最大化——主窗口有标题栏、侧栏和卡片留白，最大化以后画面周围仍有一圈非画面区域，而且全屏看完回列表时主窗口的窗口状态不该被程序改掉
- 观看的人也用 Yuhub，界面与主题跟软件本体完全一致，**全程不开浏览器**


### 异地联机
- 内嵌 EasyTier 的「跨网房间」：**没有房主/成员之分**，所有人填同一组**房间码 + 密码**、点「进入房间」即可进同一个虚拟局域网
- **准入校验**：进入后自动探测房间里有没有其他节点，房间码或密码不对会明确报错并断开，不会静默连进一个空房间
- **在线成员列表**：每人一行，显示昵称、虚拟 IP **与他正在玩的游戏**，**每个人的 IP 都有独立「复制」按钮**，点一下复制的是他自己的「IP:端口」；谁开了屏幕共享，他那一行就会多出一个**「看屏幕」按钮**，点一下直接切到屏幕共享页开始观看
- **中继节点测速**：内置节点在本机实测延迟，按快慢排进下拉（「自动」后面直接标出当前最快的那个节点与毫秒）。**每次打开这一页自动测一次，页面开着时按需点「测速」**——不做定时重测，不挂机偷跑流量；数据带着「延迟数据：x 分钟前」的时间戳，多旧一眼可见
- **内置 12 条中继、10 个可手选节点**：覆盖国内多地（成都 / 杭州 / 张家口 / 上海）、中国香港与海外备用线路。其中两条是 **WebSocket（WSS / WS）中继**——如果你的网络只放行 80/443（公司网、校园网很常见），走它们就能连上，普通 `tcp://` 会被直接掐掉
- **节点是现测现用的**：网上流传的公共节点表普遍过期，内置这批是用随包的 easytier-core 做过真握手复测、每个连 3~5 次全通的才收进来；失效的（如原来的「海波美国 UDP」口）已剔除或换协议
- **临时云盘**：进房后把文件拖进框里（或点一下那个框选文件），同房间的人就能下载；**下载时每次自己选保存位置**。谁上传、谁取消分享，所有人的列表当场同步；谁退出房间，他分享的文件立刻从所有人列表里消失。文件只存在各人自己电脑上，不经任何服务器
- **虚拟 IP 自动分配**：由 EasyTier DHCP 动态分配，遇到冲突自动改址，多人/多房间并存不会互抢 IP
- **昵称必填**：进入房间前必须填昵称——队友要靠它认人，昵称为空的节点在列表里只是一行裸 IP
- **虚拟 IP 变了会主动告知**：卡死重进后地址变动会提示，也可随时点「刷新」重读本机 IP 并重扫成员，不用退出重进
- 已开启 UDP 广播中继，依赖局域网广播发现房间的游戏（Minecraft 等）也能看到彼此
- 切换 WiFi / 热点时自动关闭虚拟局域网
- 无需 UPnP、无需自建服务器、免费

### 软件卸载
- 列出本机所有已安装程序（含应用商店应用），显示真实图标
- 调用各自官方卸载程序，并**深度清理残留**的文件与注册表项

### 自动更新
- 每次启动后台静默检查 GitHub Releases，发现新版本弹窗提示
- 设置页可手动触发检查，已是最新版本时给出明确提示
- 下载后校验 sha256，用**两步改名**替换自身 exe 并重启
- 替换失败自动回滚，不会把程序弄坏

### 外观与系统集成
- **主题包系统**：主题存于「文档 / Yuhub」，含 `theme.json` / `theme.qss` / `preview.png`，可新建或删除
- **深色 / 浅色 / 跟随系统** 三态切换，选择持久化
- **动效**：侧栏选中片、按钮 hover 反馈（自绘液态玻璃浅蓝膜，弹簧曲线）等均为逐帧动画——Qt 样式表没有 transition，所有过渡都靠代码画
- **全自定义无边框窗口**：自绘标题栏（拖动移动、双击最大化）与边缘缩放
- **系统托盘驻留**：关闭窗口后仍在通知区域，单击恢复、右键退出
- **单实例限制**：重复启动不会开第二个窗口，而是把已有窗口唤到前台
- **开机自启开关**：设置页一键开关，开机静默驻留托盘
- **高 DPI 适配**与响应式布局：功能卡片按视口宽度自动切换 3 / 2 / 1 列

## 运行与打包

```bash
# 源码运行
python main.py

# 打包单文件 exe（含图标生成）
build.bat
```

打包产物为 `dist/Yuhub.exe`。仓库内另有十二套打包后自检脚本（主题包 / 卸载页 / 跨网房间 / 房间聊天 / 自动更新 / 显卡 / 云盘 / 节点测速 / 内存优化 / 底部提示 / 屏幕共享 / 空间清理），用 `Yuhub.exe --<名字>-selftest <结果.json>` 运行。

## 目录结构

```
Yuhub/
├── main.py                  # 应用入口（高 DPI / 单实例判定 / 图标 / 字体）
├── hardware.py              # 硬件信息采集（离线）
├── live_monitor.py          # 实时监控核心
├── cleaner.py               # 空间清理引擎（Dism++ Data.xml 规则集移植 + 扫描 + 安全删除）
├── memopt.py                # 内存优化引擎（工作集回收 + 系统缓存清理，不结束任何进程）
├── sysinfo.py               # CPU 核心数采集
├── downloader.py            # 多线程下载引擎（纯标准库）
├── autostart.py             # 开机自启读写（纯标准库）
├── single_instance.py       # 单实例守卫（第二个实例敲门 → 唤醒已有窗口）
├── winadmin.py              # 进程提权判定（TokenElevation；不能用 IsUserAnAdmin 判组）
├── etier.py                 # 内嵌 EasyTier 集成（不依赖 Qt）
├── screenshare.py           # 屏幕共享引擎：抓屏 + 自研帧协议 + TCP 广播（纯标准库）
├── h264codec.py             # H.264 编码器：ctypes 直调 libavcodec（组件按需下载）
├── ffmpeg_pack.py           # FFmpeg 极简组件包的获取与校验（按需下载）
├── lan_share.py             # 临时云盘：房间内文件互传（纯标准库）
├── room_chat.py             # 房间内文字聊天（纯标准库）
├── node_probe.py            # 中继节点测速：并发探测 + 带时间戳的缓存
├── gpu_sensors.py           # 显卡温度/功耗（NVML + ADL，不依赖 Qt）
├── updater.py               # 自动更新核心（版本比对 / 下载校验 / 替换器）
├── errorlog.py              # 崩溃捕获与日志落盘
├── *_selftest.py            # 打包后自检脚本
├── build.bat / build_icon.py# 图标生成与一键打包
├── resources/               # 图标、品牌 logo、Qt 中文翻译、EasyTier 二进制
├── accel-framework/         # 加速框架（.NET 8 + YARP + **Native AOT** 子工程；AOT 单文件 10.9MB 已打进 exe，不需要 .NET 运行时）
└── ui/                      # 界面层：主题、组件、托盘、主窗口与各页面
```

## 许可

本项目内嵌了第三方可执行文件，按各自的原许可证随包携带，许可证原文就在对应的
`resources/` 子目录里：

- **EasyTier**（Apache 2.0）—— 异地联机的虚拟局域网内核，`resources/easytier/`

屏幕共享的传输层是**自研实现**（`screenshare.py`，纯标准库手写 17 字节帧头协议）；
H.264 编解码使用 FFmpeg 的 `libavcodec` / `avutil` / `swscale`，按 **LGPL-2.1+**
动态链接方式调用（构建参数与合规要点见 `resources/ffmpeg/BUILD.md`，不含 GPL 组件）。
该组件**不随 exe 打包**，由程序首次开启共享时按需下载，因此仓库与发行包里都不含
这些第三方二进制。
